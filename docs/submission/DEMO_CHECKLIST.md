# Submission demo checklist

- [ ] Run `npm run typecheck` and `npm run build` successfully.
- [ ] Show the Compact compile command and its clean completion in WSL.
- [ ] Start the proof server and show Lace configured for Midnight Preprod.
- [ ] Show the deployed contract address in the app.
- [ ] Show credential registration confirmed by the Preprod Indexer.
- [ ] Show a successful `proveAge` transaction and the gated chat unlock.
- [ ] State that DOB, salt, issuer secret, and holder secret remain local.
- [ ] State the prototype limits: mock issuer, no expiry/revocation, and no production security review.
- [ ] Keep seed phrases, private keys, raw credential JSON, and `.env` files out of the recording.
